# 绿苔巨像 (The Awakening of the Moss Colossus)
> 60-Second Cinematic Hand-drawn 2D Anime Scene (Video-as-Code Project)

本工程是依据**吉卜力工作室剧场版经典手绘动漫美学（Ghibli Anime Aesthetics）**打造的 60 秒纯代码动画电影项目。项目严格遵循 `motion-video-director` 导演宪章与日本黄金时代赛璐珞动画标准，**交付为一个完全自包含、零外部依赖的单一 HTML 文件**。

---

## 🎬 核心艺术与工艺规范 (Aesthetic & Craft Doctrine)

1. **男鹿和雄（Kazuo Oga）水粉厚涂背景**：
   - 晨曦渐变破晓天空（由深蓝幽冷逐渐转变为灿烂暖金朝霞）。
   - 顶部树冠缝隙中倾泻而下的神圣丁达尔光束（God Rays），随空气湿度产生微秒级柔和漂移。
   - 盘根错节的森林古木与长满青苔、野花的古代石柱遗迹。

2. **手绘赛璐珞机甲设计（Cel-Shaded Mech）**：
   - 参考《天空之城》古代拉普达巨兵的造型灵魂，以粗壮沉重的躯干、古青铜氧化色、斑驳红锈与剥落涂装构筑岁月沉淀。
   - 真实的物理质量表现：关节弯曲时的机械应力微震、站立时的泥土与苔藓崩塌重力、抬头仰望树冠缝隙的电影构图。

3. **防流水线 CG 负向防御（Anti-Slop Hard Bans）**：
   - 严禁 3D 塑料感、严禁扁平现代 UI 矢量曲线、严禁机械图层位移与补间漂移。
   - 采用亚像素胶片颗粒（Subpixel Film Grain）与经典的 **12fps/24fps 手墨线条微颤（Line Boil）**，让每一帧都宛如动画师在透光台上手绘的赛璐珞原画。

4. **纯代码 Web Audio 物理拟音引擎**：
   - **00:00 - 00:15**：滤波白噪声合成清晨森林微风，调频（FM）正弦波合成清脆的翠鸟/知更鸟梳羽鸣叫。
   - **00:15 - 00:30**：40Hz 次声波地壳共振（Sub-bass Rumble），晶石能量微光脉冲。
   - **00:30 - 00:45**：锯齿波带通共振模拟的空心金属应力扭曲与机械吱嘎呻吟、高压蒸汽泄气啸叫、泥土碎石崩落。
   - **00:45 - 00:60**：双引擎暴烈轰鸣点火、狂风扫荡树叶的激波扩散、高空多普勒超音速破空声，以及最终舒缓的吉卜力风格 D 大调晨曦抒情和弦。

## 🚀 运行与体验方法

1. **直接双击打开**：
   在文件资源管理器中直接双击 `index.html`，或用任意现代浏览器（Chrome、Edge、Firefox、Safari）打开。
2. **交互控制**：
   - 点击屏幕正中央的吉卜力封绘启动播放（自动初始化 Web Audio 音频上下文）。
   - **空格键**：播放 / 暂停。
   - **左右方向键（← / →）**：步进 / 快退 5 秒。
   - **底部控制条**：支持全时间轴毫秒级拖拽、静音切换、以及全屏影院模式。
