## 一、 为什么 `assets.mjs` 真实馆藏是 AI 视觉创作的“终极解药”？

在过去制作历史、文化或宏大叙事视频时，市面上的 AI 绘画工具（Midjourney, SD, DALL-E）普遍存在致命的 **“AI 塑料模板病”**：
- **细节空虚**：放大到 4K 时，金属只有假高光，没有真实的微距氧化斑驳；
- **几何乱编**：星盘的赤经刻度是鬼画符，青铜器铭文是乱填的蚯蚓文；
- **缺乏敬畏**：无法还原真实历史器物的重量感与冷峻尊严。

`taste-skill assets.mjs` 颠覆了这一范式：
1. **真实微距像素**：直接下载 4000×3000、2898×3870 原生馆藏 RAW 级影像，每一根黄铜刻线、每一枚齿轮榫卯、每一滴青铜锈蚀真实存在；
2. **严谨版权信标**：自动写入 `assets/credits.json`，在片尾或底部生成权威学术级馆藏编号（如 `met:451699` / `met:358366`）；
3. **零 API 门槛**：无需任何付费 Token 或 API Key，直通全球公有领域开放宝库。

## 四、 视听工程落地矩阵

1. **素材真实性保障**：
   - 全片素材 100% 由 `assets.mjs --get` 下载，绝不用任何 AI 假图；
   - 包含完整的 `assets/credits.json` 溯源台账。
2. **大气的 BGM 打造标准**：
   - 采用多声部交响混合架构：
     - **低频基座**：40-60Hz Sub-bass 震动与大提琴/低音号长音，赋予画面大理石般的厚重感；
     - **中频骨架**：全编制圆号 (Horn Chords) 与管风琴，营造崇高殿堂感；
     - **打击乐动力**：沉重定音鼓 (Timpani Rolls) 在节点处轰鸣；
     - **高频晶莹**：机械发条高精滴答与星辉微鸣。
   - 整体响度统一由 ITU-R BS.1770 标准母带压限至 **-14.0 LUFS**，真峰值 **-1.5 dBTP**。
3. **视觉排版与动效规约**：
   - 贯彻 `motion-video-director` 瑞士 Bento 布局与 `taste-skill` Frame 规则，杜绝一切塑料假渐变与大段堆砌文字。
